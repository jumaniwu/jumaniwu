# 11. Revenue Model

BRICKX Protocol generates sustainable revenue through multiple streams that scale with platform growth:

| Protocol NOI Share | 30% of each hotel's annual Net Operating Income — primary long-term revenue source |
|---|---|
| Marketplace Fee | 0.5% on each BRICK token secondary market transaction |
| BRX Staking Protocol Fee | Portion of BRX staking rewards flows to protocol treasury |
| Property Listing Fee | One-time fee for new property onboarding (Phase 3 onwards) |
| DAO Treasury | Governed and deployed by BRX token holder vote |

Revenue projections (base case): 2026: USD 5,000 (platform only). 2027: USD 248,000 (first acquisition). 2028: USD 948,000 (first full year hotel + platform). 2029: USD 2.15M. 2030: USD 4.8M (multiple properties).
